# ЧАСТЬ II. ПРОФЕССИОНАЛЬНЫЙ ГАЙД: ПОШАГОВАЯ РЕАЛИЗАЦИЯ

## Общая схема

```
  [Geekom A8 Max, Windows]                       [NVIDIA DGX Spark, Linux]
  ┌────────────────────────────┐                ┌──────────────────────────┐
  │  Hermes Agent (WSL2)       │ ── HTTP ────▶  │  vLLM (порт 8000)        │
  │  Custom endpoint: /v1/chat │                │  Qwen3.8-27B NVFP4       │
  │  http://<SPARK_IP>:8000/v1 │                │  OpenAI-совместимый API  │
  └────────────────────────────┘                └──────────────────────────┘
```

Ключевой принцип: **DGX Spark — это сервер инференса, Geekom A8 Max — клиент-агент.** Соединение происходит по локальной сети через OpenAI-совместимый HTTP API.

## Этап 1. Первоначальная настройка DGX Spark (First-Time Setup)

### 1.1. Подготовка перед подачей питания

> ⚠️ **Критически важно:** DGX Spark **включается автоматически** при подаче питания. Все периферийные устройства — монитор, клавиатура, мышь, сетевой кабель — должны быть подключены **до** подключения блока питания.

Подключите:
- Монитор (предпочтительно через **HDMI**, если USB-C/DisplayPort не определяется).
- Клавиатуру и мышь (USB или Bluetooth).
- Сетевой кабель Ethernet (если планируете проводное подключение — сделайте это сразу, чтобы избежать проблем с подключением позже).
- Только после этого подключите блок питания.

### 1.2. Выбор способа доступа

У вас два варианта, и выбор касается **только** первоначальной настройки — после завершения вы сможете пользоваться DGX Spark любым способом:

| Способ | Что нужно | Когда выбирать |
|---|---|---|
| **Локальный** | Монитор, клавиатура, мышь | Если есть физический доступ и периферия |
| **Сетевой** | Другой компьютер в той же сети | Если DGX Spark будет работать «headless» в серверной роли |

Для сетевого способа DGX Spark создаст Wi-Fi-сеть, к которой нужно подключиться с ноутбука или ПК. Данные для подключения (SSID и пароль) указаны в руководстве пользователя.

### 1.3. Прохождение мастера настройки

Мастер проведёт вас через шаги:
1. Выбор языка, часового пояса, раскладки клавиатуры.
2. Принятие лицензионного соглашения.
3. Создание учётной записи (имя пользователя и пароль) — **пароля по умолчанию нет**, вы создаёте его сами.
4. Настройка имени хоста.
5. Подключение к сети Интернет (Wi-Fi или Ethernet).
6. **Загрузка и установка критических обновлений** — самый продолжительный этап.

> ⚠️ **Не выключайте и не перезагружайте DGX Spark во время установки обновлений.** NVIDIA прямо предупреждает: процесс нельзя прервать, а отключение питания может повредить систему.

### 1.4. Типичные проблемы первого запуска и их решение

| Проблема | Причина | Решение |
|---|---|---|
| **SSID не виден** | Настройка уже завершена, или Wi-Fi-адаптер клиента завис | SSID транслируется только до завершения настройки. Перезагрузите Wi-Fi на клиенте или выполните цикл питания DGX Spark |
| **`spark-xxxx.local` не открывается** | Windows/macOS блокируют локальное обнаружение | Windows: профиль сети → «Частная», включить «Обнаружение сети». macOS: разрешить браузеру доступ к локальной сети |
| **Монитор не определяется** | Проблема совместимости USB-C/DP | Попробуйте **HDMI** или используйте сертифицированные VESA-кабели |
| **Нет доступа к интернету при настройке** | Captive portal или нестабильная сеть | Используйте стабильное проводное соединение или домашний Wi-Fi. Гостевые сети и мобильные точки доступа не рекомендуются |

### 1.5. Проверка после настройки

После завершения настройки и перезагрузки войдите в систему и проверьте:
```bash
# Версия ОС и ядра
lsb_release -a
uname -r

# Доступность GPU
nvidia-smi --query-gpu=name --format=csv,noheader

# Сетевые интерфейсы и IP-адрес
ip a
# или
hostname -I
```
Запомните **IP-адрес DGX Spark** в локальной сети — он понадобится для настройки Hermes Agent.
